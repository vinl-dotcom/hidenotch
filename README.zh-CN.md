# HideNotch — 隐藏 MacBook 刘海

把内置屏菜单栏背后那条区域涂黑。半透明的菜单栏采样到黑色后整条变黑，物理刘海（本身是黑的）
融入其中、视觉上消失；而桌面其余部分保持浅色——白天照常用浅色模式，不用切深色主题。

跟市面同类软件不同的是：这是一个常驻后台 agent，会监听**换壁纸 / 切 Space / 插拔显示器 / 睡眠唤醒**
等事件并**自动重新涂黑**。这正是那些软件容易“失效”的原因。

## 安装

```bash
bash build.sh          # 编译 + 打包 + 安装到 ~/Applications/HideNotch.app
bash install-agent.sh  # 启用开机自启（LaunchAgent），并立即运行
```

无需任何系统授权（不需要辅助功能 / 屏幕录制权限），也无需 sudo。

## 卸载

```bash
bash uninstall.sh
```

会停止进程、还原你的原始壁纸、删除所有文件。

## 工作原理

1. 找到带刘海的内置屏（`safeAreaInsets.top > 0`）。
2. 读取当前桌面壁纸，生成一张「原图按 fill 铺满 + 顶部一条菜单栏高度纯黑」的屏幕原生分辨率图片。
3. 用 `NSWorkspace.setDesktopImageURL` 设为该屏壁纸。
4. 后台监听相关事件，壁纸一旦被换掉就重新生成应用（另有每 5 秒的兜底轮询）。

### 外接屏保护（三重防线）

macOS 默认会在多显示器之间同步壁纸，内置屏的补丁图（带黑条）会被推到外接屏。
HideNotch 通过三道防线阻止这一问题：

1. **关闭同步**：通过 `defaults write com.apple.wallpaper StretchyCropping -bool false` 禁用
   macOS 壁纸跨屏同步。
2. **先捕获后恢复**：在修改内置屏壁纸之前，先记录每个外接屏的原始壁纸路径；修改后
   立即恢复，并在 1 秒和 3 秒后再各恢复一次，覆盖异步同步。
3. **干净壁纸兜底**：如果外接屏已被同步为补丁图，自动生成一张无黑条的干净壁纸
   （同一原图、正确分辨率）并应用。

生成的补丁图、干净壁纸和原始壁纸路径记录在 `~/Library/Application Support/HideNotch/`。

## 已知限制

- **依赖菜单栏半透明**：若开启了「系统设置 > 辅助功能 > 显示 > 减少透明度」，菜单栏会变不透明、
  不再采样背后内容，黑条将不可见。（任何同类方案都受此限制。）
- **仅支持静态图片壁纸**：若使用动态 / Aerial / 照片轮播壁纸，系统取不到单张图，工具会跳过、
  保留你的壁纸不动。建议固定用一张静态浅色图当壁纸。
- **外接显示器**：内置屏使用补丁壁纸（带黑条），外接屏会被主动恢复为原始壁纸（见三重防线）。
  如果你有意使用壁纸同步功能，建议在系统设置中手动关闭以获得最佳效果。

## 设计取舍（为什么这么做）

**为什么"看不见桌面"时也照样有效。** 那条黑藏在**一直显示**的菜单栏背后，而不是给你看桌面用的。
普通窗口（哪怕最大化）都坐在菜单栏**下方**、不会跑到菜单栏背后，所以菜单栏背后永远是壁纸顶部那条黑
→ 只要菜单栏可见，刘海就一直是隐藏的，跟你有没有在看桌面无关。唯一例外是真·全屏，那时菜单栏本就
自动隐藏、刘海也跟着没了。

**为什么用壁纸补丁而不是悬浮窗口。** 悬浮窗口方案（在菜单栏区域覆盖黑色窗口）曾经尝试过，
但存在根本性问题：窗口必须与菜单栏处于同一层级（`.statusBar`），这会覆盖菜单栏文字使其
不可见；放在菜单栏下方也不行——半透明菜单栏采样的是壁纸，不是下方的窗口。壁纸补丁方案
完全避开了这个问题，因为黑色直接存在于菜单栏所采样的壁纸中。代价是仅支持静态壁纸；
如果你使用动态壁纸，本工具无法帮助。

**和其它思路的区别。**
- *切分辨率派*（如 znotch / BetterDisplay）：把屏幕切到略矮的"无刘海"分辨率，铁定生效、不依赖透明度，
  但会**牺牲竖向屏幕空间**、非原生缩放可能发虚。
- *本工具（改壁纸涂黑）*：**不丢任何屏幕空间、原生清晰**，代价是依赖菜单栏半透明、且只适合静态壁纸。
